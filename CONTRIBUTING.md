# Contributing to MediCore

Thanks for helping improve MediCore.

## Development

1. Fork or clone the repository.
2. Create a focused branch for your change.
3. Install dependencies with `npm ci`.
4. Run `npm run typecheck` and `npm run build` before opening a pull request.
5. Keep UI changes responsive and consistent with the existing design tokens and reusable components.

## Pull Requests

Please keep pull requests focused, explain the user-facing impact, and include screenshots for meaningful visual changes.

Automated CI must pass before merging.
